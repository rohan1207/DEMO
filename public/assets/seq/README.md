# Sequence frames (DRIP landing)

Place your scroll-driven animation frames in **mobile-webp** (used for both desktop and mobile):

- **Folder:** `public/assets/seq/mobile-webp/`
- **Files:** `ezgif-frame-001.png` through `ezgif-frame-526.png` (526 frames)
- **Path:** `public/assets/seq/mobile-webp/ezgif-frame-001.png` … `ezgif-frame-526.png`

The app preloads this sequence and drives the canvas from scroll progress.
